# 🚀 Инструкция по настройке GitHub Pages

## ✅ Что было создано:

1. **`index.html`** - Главный файл сайта (копия Fire & Phoenix.html)
2. **`.nojekyll`** - Файл для отключения обработки Jekyll (важно для GitHub Pages)
3. **`README.md`** - Описание проекта
4. **`.gitignore`** - Файл для игнорирования ненужных файлов

## 📤 Шаги для публикации на GitHub Pages:

### 1. Загрузите все файлы в GitHub репозиторий

```bash
git add .
git commit -m "Add website files for GitHub Pages"
git push origin main
```

### 2. Настройте GitHub Pages:

1. Перейдите в ваш репозиторий на GitHub
2. Нажмите на вкладку **Settings** (Настройки)
3. В левом меню найдите раздел **Pages**
4. В разделе **Source** выберите:
   - **Branch:** `main` (или `master`)
   - **Folder:** `/ (root)` (корневая папка)
5. Нажмите **Save** (Сохранить)

### 3. Подождите несколько минут

GitHub обработает ваш сайт и создаст URL вида:
```
https://ваш-username.github.io/название-репозитория/
```

### 4. Проверьте сайт

Через 1-2 минуты ваш сайт будет доступен по адресу, указанному в настройках Pages.

## ⚠️ Важные замечания:

1. **Файл `index.html` обязателен** - GitHub Pages ищет именно этот файл
2. **Файл `.nojekyll` важен** - он отключает обработку Jekyll, что необходимо для правильной работы сайта
3. **Все медиафайлы должны быть в репозитории** - изображения, видео, аудио должны быть загружены
4. **Размер файлов** - GitHub имеет ограничения на размер файлов (100MB на файл). Если у вас есть очень большие видео, рассмотрите возможность использования внешних ссылок

## 🔍 Проверка структуры:

Убедитесь, что в корне репозитория есть:
- ✅ `index.html`
- ✅ `.nojekyll`
- ✅ `README.md`
- ✅ Все медиафайлы (изображения, видео, аудио)
- ✅ `Fire & Phoenix.html` (опционально)

## 🐛 Решение проблем:

### Сайт не загружается:
1. Проверьте, что файл `index.html` находится в корне репозитория
2. Убедитесь, что файл `.nojekyll` создан
3. Проверьте настройки GitHub Pages (Source должен быть `/ (root)`)
4. Подождите 5-10 минут после настройки

### Изображения/видео не отображаются:
1. Убедитесь, что все медиафайлы загружены в репозиторий
2. Проверьте, что пути к файлам в HTML правильные (относительные пути)
3. Откройте консоль браузера (F12) и проверьте ошибки загрузки

### Языки не переключаются:
1. Проверьте, что JavaScript код не заблокирован
2. Убедитесь, что файл полностью загружен

## 📞 Дополнительная помощь:

Если проблемы остаются, проверьте:
- Логи GitHub Actions (если включены)
- Консоль браузера (F12 → Console)
- Network tab в DevTools для проверки загрузки файлов
