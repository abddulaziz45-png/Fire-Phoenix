1. Архитектура проекта

Сайт состоит из 10 основных разделов, организованных в одностраничном формате с плавной навигацией.

1.1 Структура сайта

Header (sticky navigation)
→ Animation Banner (Canvas effects)
→ Hero Section
→ Section 1: "Where did it begin?"
→ Section 2: "Fire Ignition Animation"
→ Section 3: "Press vs Map Slider"
→ Section 4: "Ruin Cult to Hope"
→ Section 5: "Detailed Timeline"
→ Section 6: "Video Gallery"
→ Section 7: "Cow Myth"
→ Section 8: "Interactive Game"
→ Section 9: "Quiz (30 questions)"
→ Section 10: "Legacy & Consequences"
→ Footer

2. Технические модули

2.1 Основные компоненты

  • main.js - инициализация, переключение языков, поиск
  • slider.js - интерактивный слайдер пресса vs карты
  • canvas-animations.js - эффекты огня, искр, пепла (3 слоя)
  • game.js - интерактивная игра "Спасти Чикаго"
  • quiz.js - система викторины (30 вопросов)
  • timeline.js - видеоплеер временной линии

2.2 Организация файлов

ПапкаСодержимое
images/Исторические фото, иллюстрации прессы, карты
videos/Анимации временной линии, видео (7+ файлов)
audio/Многоязычные аудиозаписи
