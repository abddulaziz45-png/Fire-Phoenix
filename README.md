# Fire & Phoenix - Chicago 1871

Интерактивный мультимедийный веб-сайт о Великом пожаре Чикаго 1871 года.

## 🎯 О проекте

Этот проект исследует, как иллюстрации Harper's Weekly и миф о "корове О'Лири" сформировали коллективную память и создали образ "стойкого" Чикаго после пожара 1871 года.

## 🌐 Языки

Сайт поддерживает 4 языка:
- 🇷🇺 Русский (Russian)
- 🇬🇧 Английский (English)
- 🇮🇹 Итальянский (Italian)
- 🇹🇷 Турецкий (Turkish)

## 📁 Структура проекта

- `index.html` - Основной файл сайта
- `Fire & Phoenix.html` - Альтернативный файл сайта
- Все медиафайлы (изображения, видео, аудио) находятся в корневой папке

## 🚀 Использование

Откройте `index.html` в браузере для просмотра сайта.
